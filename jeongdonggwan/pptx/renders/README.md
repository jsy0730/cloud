# 렌더

Blender 5.2 Cycles(192 샘플, OpenImageDenoise), 하늘 HDRI · 텍스처 · 나무는 Poly Haven(CC0). 주변 건물은 OpenStreetMap 높이 자료와 단순 가상 매스. **실제 설계안이 아닌 개념 볼륨 모델**임.
JPG는 가로 1920px 이하 · 품질 90으로 줄인 것이며 PNG 원본은 Google Drive `04_렌더`에 있음.

| 폴더 | 내용 | 쓰인 곳 |
|---|---|---|
| `v02_첫렌더` | 첫 Blender 렌더 7컷(조감 · 정면 · 밤 · 가로 · 옥상 · 소로 · 선큰) | v02~v05 투시도 · 콘셉트 |
| `v03_외피_형태_대안` | 사례 차용 외피 3종(Saint-Luc · Lincoln · Blaibach, 각 2컷) · 형태 A~C 매스(조감 · 가로) | 외피 대안 · 형태 대안 쪽 |
| `v03_디자인제안_kinetic_green_lantern` | 외피 디자인 제안 3종(키네틱 블레이드 · 그린 월 · 랜턴) 각 2컷(마지막 완결 세대 x) | 제안용(덱 미사용) |
| `v06_최종렌더` | 경사 슬랫 · 상세 계단 · 검은 아스팔트 · 인도 · 가로수를 반영한 최종 세트 | v06~v09 |
| `볼륨도출_축측` | 볼륨 도출 5단계 축측투영(Blender Cycles + Freestyle) | 볼륨 도출 쪽 |

## v06_최종렌더 → 최신본(v09) 사용처

| 파일 | 장면 | v09에서 쓰인 곳 |
|---|---|---|
| `f3_hero_sw` | 전포대로(서측)에서 본 주간 외관 | 표지 · 콘셉트 낮 · 투시도 큰 그림 |
| `f3_night_sw` | 같은 시점의 밤 | 목차 · 콘셉트 밤 · 투시도 작은 그림 |
| `f3_street_nw` | 서전로 × 전포대로 모퉁이 | 투시도 작은 그림 |
| `f3_drone_a` | 남서쪽 상공 드론 시점 | 최종안 조감 |
| `f3_roof_view` | 옥상 광장(+21.1m) | 조망 쪽 옥상 시뮬레이션 |
| `f3_stair_close` · `f3_lane_entry` · `f3_sunken` | 끝 코어 계단 근접 · 소로 안 · 선큰 | v06~v08 투시도 Ⅱ에서 사용, v09에서 쪽 삭제로 미사용 |
| `f3_aerial` | 조감(고정 시점) | 미사용(드론 시점으로 대체) |
| `alt4_*` | 외피 대안 3종(같은 도로 · 계단 조건) | 사례 차용 외피 대안 |
| `form4_*_aerial` | 형태 대안 A~C 조감 | 형태 대안 3종 |

시험 컷(`dbg_*`, `t_*`, `q_*` 등)은 정리하지 않고 제외했습니다.
