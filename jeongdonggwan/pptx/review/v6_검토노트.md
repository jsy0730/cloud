# 정동관 v6 · 검토 노트

## 적용한 검토 도구
어제 내려받아 쓴 PPT 디자인 검토 스킬 **carnot-tech/jinba-consulting-pptx-skill**(`slide-rules.md` 규약 + `check_deck.py` · `check_deck_layout.py`)을 v6에 적용함.
- 규약 전문(`references/slide-rules.md`, §2 타이틀 · §4 레이아웃 · §5 색과 도형 · §7 문장)을 읽고 해당 항목만 공설기 v1.2와 충돌하지 않는 범위에서 적용
- 공설기 v1.2가 지시한 요소(용어 헤더, 섹션 탭, 출처 · 담당자 푸터)는 유지함. 규약과 충돌하는 곳은 공설기가 우선
- 앞서 임의로 쓴 impeccable은 웹 UI용이라 슬라이드 검토에 맞지 않았음(v5 노트 참고). v6는 위 스킬 기준임

## 규약 적용 결과

| 규약 | 적용 내용 |
|---|---|
| §4.8 하단 결론 밴드 금지 | 모든 쪽에서 하단 "결론" 밴드를 제거. 결론은 헤더 문장(소제목 칸)으로 올림. 투시도 쪽의 사양 한 줄은 캡션으로, 법규 쪽의 조건부 안내는 "주의" 박스로 |
| §2.1 · 2.2 타이틀은 결론 문장 | 헤더 소제목을 주제 라벨에서 결론 문장(~함 · ~임)으로 바꿈. 23개 쪽 전부 |
| §2.4 개수를 제목에 넣지 않음 | "용도 여섯 가지", "적합 3건 · 조건부 3건" 같은 개수 제목을 내용 서술로 교체 |
| §2.11 · 2.23 과장 금지 | "공연 소음이 문제 되지 않음"을 "건물 안에서는 문제가 적음 (5F 업무 공간만 이중창)"으로 낮춤. 방문객 수 문장에 "주말 이틀"을 명시 |
| §5.3 둥근 모서리 · 채움 박스 테두리 | NoteBox를 직각 · 테두리 없음으로 변경. 사례 타일 · 설계 의도 박스의 채움+테두리 조합을 테두리만으로 |
| §5.50 채움은 의미가 있을 때만 | 번호 카드 · 사례 사실 카드의 회색 채움을 구분선으로 바꿈 |
| §4.23 한 칸에 소제목 둘 금지 | 사업 배경 Ⅱ 하단 카드 등 한 칸 한 소제목으로 정리 |

## 슬라이드 내용 변경 (사용자 요청)
- 사업 배경을 1쪽에서 3쪽으로: Ⅰ(변천 · 지금/앞으로 · 확보율 · 사당 사례), Ⅱ(먹고 · 보고 · 듣고), Ⅲ(왜 한 건물인가 · 사례 4곳)
- 부지 선정: "왜 꼭 이 땅인가" 이유 5개로 재구성(교통 · 입지 일반론 삭제)
- 사례 쪽: 체크 표시 문장 → 도면 번호와 같은 번호 배지 + 키워드 + 문장
- 최종안 조감: 드론 시점 렌더로 교체
- 투시도 · 콘셉트 · 표지 · 목차: 새 렌더(경사 슬랫, 상세 계단, 검은 아스팔트, 인도, 가로수)

## 열려 있는 항목
1. **먹고 · 보고 사진**: 전포 인기 가게 사진은 저작권상 직접 찍은 사진이나 가진 사진을 쓰기로 했으나 아직 받지 못해 넣지 못함. 파일을 주시면 사업 배경 Ⅱ의 먹고 · 보고 카드 위쪽에 넣음.
2. **법령 조항 번호**(주차장법 시행규칙 제5 · 6조 등)와 수치(경사로 17%, 높이)는 저장소 조사값을 그대로 쓴 것이므로 제출 전 법제처 원문으로 한 번 더 확인 필요.
3. 사례 차용 외피 대안 · 형태 대안 렌더에는 슬랫 대신 각 사례의 외피 재질을 썼음(요청 취지에 맞는 비교용).
