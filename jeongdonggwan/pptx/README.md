# 전포 정동관(停動館) — PowerPoint 발표자료 정리본

부산진구 전포동 207번지 일대 53필지(4,964.5㎡) 복합주차장 **정동관**의 건축계획 발표자료를 PowerPoint로 만든 과정과 결과를 모았습니다.
공설기 v1.2 디자인 시스템(색 · 글꼴 역할 · 헤더 · 푸터)을 따르며, 렌더는 Blender Cycles로 만들었습니다.

- 정리일: 2026-10-13
- **최신본: [v14 (25장)](versions/v14_문구다듬기_도구흔적제거_25장.pptx)** — v13의 문구를 보고서 말투로 다듬고 파일 속 제작 도구 흔적을 지운 파일(2026-10-15). 바뀐 문구 전체는 [`review/v14_문구변경_전후.md`](review/v14_문구변경_전후.md)
- 제출본: **[v11 (25장)](versions/v11_사용자수정2차_제출본261002_25장.pptx)** · [PDF](final/261002-전포동주차타워사업계획서-건물주변구체화-정성윤.pdf) — v09를 PowerPoint에서 직접 고쳐 저장한 파일(15:35 저장, 이름 `261002-…-정성윤`)
- Claude가 빌드한 마지막 버전: [v09 (25장)](versions/v09_투시도2_확인할것삭제_25장_최종.pptx) · [PDF](final/전포정동관_최종본_v9.pdf). 파일명의 "최종"은 이 빌드의 마지막이라는 뜻이며, 그 뒤 사용자가 고친 v10 · v11이 더 나중 파일임
- 이 폴더는 저장소의 기존 HTML 기반 작업(`../decks/full`, `../build`, `../research`)을 PowerPoint로 옮긴 결과와 그 과정입니다.

## 다시 만드는 법

- Claude 빌드(v09까지)의 빌드 코드: [`source/deck/v09_complete`](source/deck/v09_complete) (자세한 순서는 [`source/README.md`](source/README.md))
- v10 · v11은 사용자가 PowerPoint에서 직접 고친 파일이라 빌드 코드로 다시 만들 수 없음. v12 · v13은 v11 .pptx의 XML을 직접 고쳐 쪽 순서만 바꾼 파일, v14는 그 문구를 [`source/v14_humanize.py`](source/v14_humanize.py)로 고친 파일. 이후 수정은 v14를 직접 열어 편집하고 그 .pptx를 직접 열어 편집하고, 빌드 코드의 v09를 다시 돌리면 사용자 수정이 사라지므로 주의
- 필요한 것: Windows + PowerPoint(텍스트 높이 실측용), Node 18+ (`pptxgenjs`), Python 3 (Pillow · matplotlib · shapely), 글꼴 Malgun Gothic · Noto Serif KR
- 렌더: Blender 5.2 + Poly Haven 자산(CC0), [`source/blender`](source/blender)
- 사례 사진 · 지도 원본 등 제3자 저작물은 저장소에 넣지 않았습니다. 완전한 재빌드에 필요한 이미지 폴더는 Google Drive 정리본의 `03_모델_도면` 아래에 있습니다.

1. 먹고 · 보고 카드(사업 배경 Ⅱ)의 가게 사진은 v10에서 사용자가 넣음(Claude 빌드 v09까지는 없었음). 사진 출처 · 촬영자 표기는 아직 없음
2. 소음 dB은 실측이 아닌 가정 교통량 기반 개략 추정. v10에서 슬라이드의 "현장 실측으로 교체 필요" 문구가 지워졌으나 값은 여전히 추정임
3. 법령 조항 번호와 수치(주차장법 시행규칙 제5 · 6조, 경사로 17% 등)는 저장소 조사값 그대로이므로 제출 전 법제처 원문 확인 필요
4. 평택 JS타워 사진은 출처 미확인(저장소 자료), 도면 미공개로 사진 판독
5. 형태 대안 A~C는 외피 · 매스만 바꾼 비교용으로 주차 대수 · 법규 · 구조를 다시 검토하지 않음
6. 투시도 Ⅱ 삭제로 끝 코어 계단 근접 렌더(`f3_stair_close`)와 소로 안 렌더(`f3_lane_entry`)는 덱에서 빠졌고 `renders/`에만 있음
7. 공설기가 지정한 Pretendard가 없어 맑은 고딕으로 대체
8. 표지에 학번이 들어 있고 사례 사진은 제3자 저작물이므로, 저장소를 외부에 공개할 때 확인 필요
9. v10 · v11에서 지워진 주의 문구(투시도는 개념 볼륨 모델이며 실제 설계안이 아님, 구청 발표 수치는 다른 사업이 병행된 기간이라 주차 확충만의 효과는 아님)는 v09까지의 슬라이드에는 있었음. 제출본에서 뺄지는 사용자 판단이며 자료의 성격은 그대로임
