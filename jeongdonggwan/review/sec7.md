## 볼륨 도출과 최종안

### 볼륨 도출 5단계

| 단계 | 결정 | 이유 |
|---|---|---|
| ① 53필지 합필 | 서측 + 소로 + 동측 4,964.5㎡ | 서측 쐐기만으로는 건축 가능 바닥이 약 920㎡라 램프가 면적을 잠식함 |
| ② 소로 = 차량 전용 차로 | 1층 층고 7m, 소로 자리는 차로로 비움 | 남단 진입·북단 진출로 차량을 소로에 모으고 가로에는 차가 드나들지 않게 함 |
| ③ 2층부터 한 판 | 소로 위로 이은 바닥, 북·남 3m 이격 | 한 층 약 4,232㎡의 정형 바닥, 법정 이격 확보 |
| ④ 두 끝을 비워 코어로 | 동측 북단·서측 남단에 개방 순환 계단 + 승강기 | 주차가 어려운 좁은 끝을 사람 이동의 중심으로, 건폐율 87.1% |
| ⑤ 스킵플로어·홀·광장 | 서·동 판을 소로 위에서 반 층 엇갈림, 6F 가변홀, 5F 지붕 옥상 광장, 지하 공연장 | 램프 면적을 줄이고, 비는 시간과 위아래 층에 공연·체육·광장을 담음 |

### 최종안 요약

| 구분 | 내용 |
|---|---|
| 1층 | 서측: 서점·카페·공연 로비 / 소로: 차량 전용 차로 / 동측: 근생 소점포·램프·정산·이륜차 |
| 2~4층 | 스킵플로어 주차(서측 판 7.0·10.3·13.6m, 동측 판 +1.65m) |
| 5층 | 상인회·회의·공유오피스 1,200㎡ + 전환 가능 주차층 |
| 6층 | 생활체육·공연 가변홀(층고 8m) + 옥상 광장(약 1,380㎡, 5F 지붕) |
| 지하 | B1·B2 공연장 200석(선큰 마당으로 진입), B3·B4 주차·설비 |
| 코어 | 끝 코어 2곳(지상 개방 순환 계단 + 승강기, 지하 특별피난계단) + 보조 피난계단 2곳 |
| 외피(투시도 기준) | 주차층 전돌 스크린, 6F 세로 핀 유리, 붉은 순환 계단. 6F 외피는 미정 |

### 투시도

- 주간 북서(서전로×전포대로 모퉁이), 주간 남서(전포대로, 끝 코어②), 조감(남서 상공), 야간 남서 4장을 만듦. 주변 건물은 OpenStreetMap 높이 자료로 단순화함.
- 야간에는 주차층을 어둡게, 1층·6F 홀·순환 계단을 밝게 해 "밤에는 공연과 옥상 광장"을 보이게 함.
