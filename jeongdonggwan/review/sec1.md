## 한눈에 보기

전포 정동관은 소로3류 부지까지 포함한 53필지 4,964.5㎡를 한 대지로 묶어 짓는 지하 4층·지상 6층+옥상의 거점형 공영주차장임. 콘셉트는 **낮에는 주차장, 밤에는 공연과 옥상 광장**.

| 항목 | 내용 |
|---|---|
| 대지 | 전포동 207번지 일대 53필지 4,964.5㎡, 일반상업지역·방화지구 |
| 규모 | 지하 4층·지상 6층+옥상, 지상 약 29.1m·지하 약 15.6m |
| 연면적 | 43,623.7㎡ (지상 23,923.7 + 지하 19,700.0) |
| 건축면적·건폐율 | 4,322.1㎡ · 87.1% (주차전용건축물 상한 90%) |
| 용적률(지하 제외) | 481.9% (상한 1,500%) |
| 주차 | 약 600대 · 주차 비율 75.62% (요건 70% 이상) |
| 핵심 장치 | 소로 = 차량 전용 차로, 두 끝 = 개방 순환 계단 코어, 소로를 이음매로 한 스킵플로어, 지하 공연장 200석, 6F 가변홀, 옥상 광장 |

### 이번 판에서 바뀐 점

- 법령을 직접 확인해 건폐율 90% 상한과 건축선 3m 이격을 반영함 → 북·남 3m를 비우고 두 뾰족한 끝을 코어로 비움.
- 소로는 차량 전용 차로로 쓰고(남단 진입, 북단 진출), 보행은 1층 외곽으로 돌림. 진입·진출 사이에 횡단보도 1곳.
- 주차는 약 600대로 표기함(수요 근거로 방어 가능한 400~700대 범위).
- 대안 비교(Alt 1·2·3)는 빼고 볼륨 도출 5단계로 바꿈.
- 공연장 200석, 6F는 생활체육·공연 가변홀로 한정, 5F 일부는 전환 가능 층.
- 이륜차·자전거 주차와 전기차 충전 구획을 넣음.
