# 전포 정동관(停動館) — 프로젝트 요약 (검토용)

학부 2학년 건축 공학설계기초 텀프로젝트. 부산 부산진구 전포동 207번지 일대 복합주차장. 콘셉트: "낮에는 주차장, 밤에는 광장" (停=멈춤, 動=움직임).

## 배경
- 부산 주차장 확보율: 전체 130.5%, 상가밀집지역 69% (2022, 부산시 주차종합계획/파이낸셜뉴스). 시는 2025년까지 6,092면 추가, 1,995억 원.
- 전포동: 이면도로 불법주차, 보행자가 도로 중앙으로 걷는 위험, 상인회 사무실·주민 휴게공간 없음(현장 답사 관찰). 소규모 필지에 저층 점포 밀집 → 부설주차장 확보 불가 → 거점형 주차장 필요.

## 대지
- 53필지 4,964.5㎡ = 서측 쐐기 1,531.9(19필지) + 소로3류(폭 약 6m, 8m 미만) 부지 733.1(5필지) + 동측 삼각 블록 2,699.5(29필지). 블록 약 42m × 122m, 장축 정남북.
- 일반상업지역, 방화지구, 가로구역별 최고높이(기준 130m/최고 180m). 서측 전포대로(광로2류), 북측 서전로, 남측 전포대로224번길, 동측 이면도로. 동측 약 45m부터 제3종일반주거지역.
- 소로: 면적 계산에는 대지로 편입하지만 도로는 유지하고 "자동차 출입로"로 사용(사용자 결정). 2층 이상은 소로 위로 이어진 한 판, 지하 B1~B4도 소로 밑까지 통합. 1층은 층고 7m, 소로 자리는 차로.
- 207-15·79는 토지이용계획에 제3종일반주거지역도 표기(확인 필요). 207-84·85는 지목 대인데 도로로 쓰임.
- 역: 서면역(1호선) 737m, 전포역(2호선) 529m. 버스 정류장 68~146m. 전포카페거리·전리단길·전포사잇길 사이.

## 건물
- 지하 4층·지상 6층+옥상. 층고 1F 7.0 / 2~4F 3.3(스킵플로어) / 5F 4.2 / 6F 8.0 → 지상 29.1m. B1·B2 4.5 / B3·B4 3.3 → 지하 15.6m.
- 연면적 47,347.4㎡(지상 27,489.4 + 지하 19,858). 주차 35,916㎡(75.86%) 약 970대(2.5×5.0m 구획, 1대당 약 35㎡). 문화·공연 4,900 / 상업·상인 3,050 / 코어 2,581 / 설비 900.
- 층별: RF 옥상광장(약 1,565㎡ 옥외, 밤 개방, 외부 계단으로 거리에서 연결) / 6F 체육·공연 겸용홀 3,400(홀 1,500·다목적 900·지원 600·코어 400) / 5F 상인회·회의·공유오피스 1,200 + 주차 96대 / 2~4F 주차 각 130대 / 1F 서점 400·카페 400·공연 로비 300·근생 600·하역 150·코어·진출입·정산·램프 1,800 (1F 4,231.4) / B1~B2 공연장 120석(+로비·분장) + 주차 / B3~B4 주차 + 전기·펌프·저수조.
- 건폐율 현재 100%(2층 이상 투영), 용적률 553.7%(지상 연면적/대지). 주차전용건축물로 가정(법령 검토 진행 중: 건폐율 상한 90% 가능성 → 수정 예정).
- 코어 3곳. 차량: 서전로→소로 북단 진입, 소로 남단→전포대로로 진출(일방, 진입·진출 분리). 하역 서측 남단.
- 향: 남향은 동측 1층 남단과 옥상. 서측 면 주차층 타공 차양. 소음원 전포대로·서전로, 소음 실측 없음. 공연장 지하, 6층 홀 이중 차음 지붕. 조망 황령산(동 1.5km), BIFC(남 1.2km), 서면 도심.
- 외피: 주차층 전돌/타공판 스크린, 동측 면 녹화, 6층 반투명 채널글라스(밤에 빛남), 1층 유리.

## 사례
헤르마 주차빌딩(용인 죽전, 1층 상가·반투명 패널), 평택 JS타워(스킵플로어), Concert House Blaibach(지하 공연장), 1111 Lincoln Road(주차층을 행사공간으로), Park 'n' Play(옥상 놀이터+외부 계단), Saint-Luc(열린 외피·목재 루버, 위치·설계자 미확인), Ballet Valet(입면 녹화).

## 사용자가 이미 정한 것
- 용도 6가지 유지. 주차 비중 75.9% 유지. 진입 2곳 검토 안 함. 사업성은 다루지 않음. 지하 굴착·지반 내용은 뺌. 소음·조명 운영시간은 나중에. 대안(Alt 1·2·3) 비교 장은 삭제. 팀·일정 장 필요 없음.
- 진행 중: 법령 검토, 주차 수요 산정(970대 근거), 반경 내 공연·체육시설 현황조사, 단면 스케치, 투시도.
